# Resident Evil 0 HD Remaster — UI Speed Tweaks

바이오하자드 0 HD REMASTER의 저장·불러오기·설정 메시지 대기를 줄이고 공용 화면 페이드·로드 후 문장·파트너 전환 화면 효과·저장 슬롯 타자기 출력의 속도를 조절하고, 타자기 안내 문장을 건너뛰며 아이템 운반 장치를 빠르게 하는 ASI 모드입니다. UI 시간을 조절하며, 렌더링 FPS나 디스크 처리 속도를 높이는 모드는 아닙니다.

[English](README.md)

## 지원 환경

`MasterRelease Jan 28 2025 16:45:59`로 식별되는 Steam PC 32비트 게임과 `scripts` 폴더를 읽는 기존 32비트 ASI 로더가 필요합니다. 해당 로더를 사용하는 Windows 또는 Wine 설치 환경에서 사용할 수 있습니다. 다른 게임 빌드는 지원하지 않으며, 명령이 일치하지 않으면 변경을 적용하지 않습니다.

## 설치

1. 게임을 종료하고 기존 `scripts` 폴더를 백업합니다.
2. `re0hd.exe`가 있는 게임 폴더를 엽니다. Steam에서는 **관리 → 로컬 파일 보기**를 사용합니다.
3. 패키지의 `scripts/RE0.UISpeedTweaks.asi`와 `scripts/RE0.UISpeedTweaks.ini`를 게임의 `scripts` 폴더에 복사합니다. 폴더가 없으면 만듭니다. 기존 ASI 로더와 다른 모드 파일은 유지합니다.
4. 게임을 실행합니다. 업데이트할 때 직접 수정한 INI가 있다면 기존 설정을 유지합니다.

이전 NoUIWait 버전에서 업데이트한다면 `scripts/RE0.NoUIWait.asi`를 삭제하고 기존 INI 이름을 `RE0.UISpeedTweaks.ini`로 바꾸면 설정을 유지할 수 있습니다. 두 버전을 함께 사용하지 마세요.

패키지에는 ASI 로더가 포함되지 않습니다. 로더를 사용하지 않는다면 [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader)의 **Win32** `dinput8.dll`을 `re0hd.exe` 옆에 넣은 뒤 실행하세요. 기존 `dinput8.dll`이 있다면 덮어쓰기 전에 백업하세요.

## 설정

`scripts/RE0.UISpeedTweaks.ini`를 수정한 뒤 게임을 다시 실행합니다.

```ini
[Timing]
WaitSeconds=0.3
FadeSpeed=2.0
RecapTextSpeed=4.0
PartnerTransitionSpeed=2.0
SaveTextSpeed=4.0
SaveTextHoldSeconds=0.3
DumbwaiterSpeed=5.0
DeviceSpeed=2.0

[Typewriter]
SkipTypewriterMessage=1
```

- `WaitSeconds`: 저장·불러오기·설정 UI의 최소 대기 시간(초)입니다. 범위는 `0`–`30`, 기본값은 `0.3`입니다. `3`은 원래 대기 시간입니다. `0`에서도 자동 종료 알림에는 1ms 타이머를 남겨 정상적으로 닫히게 합니다. 실제 저장 완료와 오류는 계속 확인합니다.
- `FadeSpeed`: 공용 화면 페이드의 속도 배율입니다. 범위는 `0.1`–`20`, 기본값은 `2`입니다. `1`은 원래 속도, `2`는 소요 시간의 절반, `3`은 3분의 1입니다. 즉시 전환은 그대로 유지합니다.
- `RecapTextSpeed`: 로드·도입 내레이션 문장(공통 메시지 88–95)의 글자 출력 배율입니다. 범위는 `0.1`–`20`, 기본값은 `4`입니다. `1`은 원래 속도이며 `4`는 일반 메시지와 같은 출력 간격입니다. 다른 대사와 문장 완성 후 유지 시간은 바꾸지 않습니다.
- `PartnerTransitionSpeed`: 파트너 전환 화면 효과의 속도 배율입니다. 범위는 `0.1`–`20`, 기본값은 `2`입니다. `1`은 원래 속도입니다. 효과의 진행·유지·감쇠 시간을 조절하며, 실제 전환 준비 상태 확인과 종료 처리는 유지합니다. 실제 조작권·카메라 전환 시간이 같은 배율로 줄어드는 것은 아닙니다.

- `SaveTextSpeed`: 저장 성공 후 슬롯에 찍히는 타자기 글자 출력 배율입니다. 범위는 `0.1`–`20`, 기본값은 `4`이며 `1`은 원래 속도입니다. 갱신 중인 슬롯의 한 줄·두 줄 출력에만 적용하며 저장 완료 확인과 줄 이어쓰기는 유지합니다. 타자기 소리의 음높이와 재생 속도는 그대로 두고, 출력 배율에 맞춰 재생 횟수만 줄입니다(`4`에서는 약 네 글자당 한 번).
- `SaveTextHoldSeconds`: 저장 슬롯의 글자 출력이 끝난 뒤 기다리는 시간(초)입니다. 범위는 `0`–`30`, 기본값은 `0.3`이며 `2`는 원래 대기입니다. `0`은 다음 UI 갱신에서 진행합니다. `WaitSeconds`, `SaveTextSpeed`와 독립적으로 조절합니다.
- `DumbwaiterSpeed`: 아이템 운반 장치(열차 식당차, 연구소)를 열 때와 아이템을 고른 뒤의 대기를 빠르게 합니다. 범위는 `1`–`50`, 기본값은 `5`이며 `1`은 원래 속도입니다. 값을 크게 하면 사실상 건너뜁니다. 운반 장치 애니메이션은 원래 속도로 재생되므로 중간에 끊길 수 있습니다.
- `DeviceSpeed`: 연구소·처리장·공장의 엘리베이터와 리프트 이동을 빠르게 합니다. 범위는 `1`–`50`, 기본값은 `2`이며 `1`은 원래 속도입니다. 리프트가 움직이는 동안 액션 버튼을 누르면 나머지를 건너뜁니다. 퍼즐 연출에는 적용하지 않습니다.
- `SkipTypewriterMessage` (`[Typewriter]` 섹션): `1`(기본값)이면 타자기 안내 문장을 건너뛰고 저장 선택지를 바로 표시합니다. 선택은 직접 합니다. 잉크 리본이 없으면 안내를 생략합니다. re0box 아이템 박스 모드가 켜져 있으면 잉크 리본 없이 타자기를 조사할 때 아이템 박스가 바로 열립니다. `0`은 원래 메시지입니다.

누락되거나 잘못된 값은 기본값을 사용합니다. 게임 폴더의 `RE0.UISpeedTweaks.log`에서 적용 여부와 읽은 설정값을 확인할 수 있습니다.

## 적용 범위와 삭제

검정·흰색·사용자 지정 색상을 쓰는 공용 화면 페이드의 모든 호출에 적용됩니다. 같은 효과를 사용하는 장면 전환도 포함합니다. 독립적인 팝업·커서·리소스 애니메이션은 대상이 아닙니다. 저장이나 에셋 로딩 등 실제 작업은 설정한 UI 대기 시간보다 오래 걸릴 수 있습니다.

원래 동작으로 돌아가려면 게임을 종료하고 `scripts/RE0.UISpeedTweaks.asi`를 삭제한 뒤 다시 실행합니다. INI와 로그도 삭제할 수 있습니다. 모드는 게임 실행 파일이나 세이브 파일을 수정하지 않습니다.

## 빌드

빌드할 컴퓨터에 Python 3.10 이상과 `i686-w64-mingw32-gcc`가 필요합니다.

```sh
python3 build.py
```

패키지는 `dist/RE0-UI-Speed-Tweaks-1.3.0.zip`에 생성됩니다. 빌드는 게임을 설치하거나 실행하지 않습니다. 빌드에 게임 실행 파일이나 에셋은 필요하지 않습니다.
